# 🤖 SmartRuleBot

**A rule-based conversational chatbot built with Python**

SmartRuleBot is a lightweight, interactive chatbot developed using Python. It uses predefined rules, keyword matching, and conditional logic to understand user inputs and generate appropriate responses.

The project demonstrates fundamental concepts of **Python programming, string processing, conditional statements, functions, loops, and user interaction**.

## ✨ Features

* 💬 Interactive text-based conversation
* 🧠 Rule-based response system
* 🔍 Keyword and pattern matching
* 👋 Greeting and conversational responses
* ❓ Handles unknown inputs gracefully
* 🚪 Exit command support
* ⚡ Lightweight and dependency-free
* 🖥️ Runs directly in the terminal

## 🛠️ Technologies Used

* **Python 3**
* Conditional Statements
* Functions
* Loops
* Strings
* Lists / Dictionaries
* Console Input & Output

## ▶️ How to Run

### 1. Clone the repository

git clone https://github.com/vickykuthe/CodeAlpha.git


### 2. Navigate to the project

cd CodeAlpha/SmartRuleBot

### 3. Run the chatbot

python main.py

💻 Example

🤖 SmartRuleBot: Hello! How can I help you?

You: hello
Bot: Hello! Nice to meet you.

You: what can you do?
Bot: I can answer basic questions and have a simple conversation.

You: bye
Bot: Goodbye! Have a great day! 👋
