# 🎮 Hangman Pro

**An interactive and feature-rich Python Hangman game**

Hangman Pro is a console-based word guessing game developed with Python. The project goes beyond a basic Hangman implementation by introducing **categories, difficulty levels, hints, scoring, player statistics, and a persistent leaderboard**.

The project demonstrates practical application of **Object-Oriented Programming, modular architecture, JSON data handling, randomization, input validation, and game logic**.

## ✨ Features

* 🎮 Interactive console gameplay
* 📚 Multiple word categories
* 🎯 Easy, Medium & Hard difficulty levels
* ❤️ Limited lives and attempts
* 💡 Hint system
* 🏆 Dynamic scoring system
* 🥇 Persistent leaderboard
* 📊 Player statistics
* 🔤 Duplicate-guess detection
* 🎲 Random word selection
* 💾 JSON-based data storage
* ⚠️ Input validation
* 🧩 Modular Python architecture

## 🏆 Scoring System

The score is calculated based on:

* Word length
* Number of incorrect guesses
* Hints used

Longer words provide higher base scores, while incorrect guesses and hints reduce the final score.
